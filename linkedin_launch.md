## 📑 How to Create Your LinkedIn PDF Carousel

LinkedIn's algorithm heavily favors **PDF Document Posts** (it turns them into an interactive swipeable carousel). Since you already have automated Playwright tests running in your GitHub Actions, you have a huge advantage!

Here is the easiest way to create a gorgeous, professional PDF carousel:

**Step 1: Download Your Automated Screenshots**
1. Go to your GitHub Repository -> **Actions** tab.
2. Click on the latest successful workflow run.
3. Scroll down to **Artifacts** and download the `e2e-screenshots.zip` file (this contains the 2.1 MB of perfect screenshots Playwright took for you!).
4. Extract the ZIP on your computer.

**Step 2: Use Canva for the Layout**
1. Go to **Canva.com** (it's free) and click **"Create a design"**.
2. Select **"Instagram Post (Square - 1080 x 1080 px)"** (Square aspect ratio is proven to perform best for LinkedIn PDFs).
3. Create 4 to 6 slides:
   * **Slide 1 (Title):** A bold title like "I built a Zero-Dependency PHP MVC Framework 🚀" with the Admin Dashboard screenshot.
   * **Slide 2 (Features):** Screenshot of the Add Fee/Student page with bullet points.
   * **Slide 3 (Student Portal):** Screenshot of the Mobile View (tablet/mobile).
   * **Slide 4 (Testing):** Screenshot of your GitHub Actions passing 100% (This proves to recruiters that you know CI/CD!).
   * **Slide 5 (Call to Action):** "Link in the comments! Check out the GitHub."

**Step 3: Export as PDF**
1. In Canva, click **Share -> Download**.
2. Change the File Type to **PDF Standard**.
3. Download it to your computer.

**Step 4: Post to LinkedIn**
1. Go to LinkedIn and start a post.
2. Paste the text from the top of this document.
3. Click the **"Add a document"** icon (it looks like a piece of paper).
4. Upload your new Canva PDF.
5. Hit **Post** and watch the engagement roll in!
